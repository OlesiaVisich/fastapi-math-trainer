# Math Trainer API

Этот проект представляет собой REST API для генерации и управления математическими заданиями.

## Технологии

- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication
- Docker Compose
- Pytest

## Запуск

1. Установите Docker и Docker Compose
2. Выполните:

```bash
docker-compose up --build
